# イーズ予備校 Webサイトリニューアル提案デモ(非公式)
公式サイトではありません。提案用プロトタイプです(`noindex`設定済み)。独自ドメインでの公開はしないでください。

## 起動
`npm install` → `npm run dev`(開発)/ `npm run build`(`dist/`生成)/ `npm run preview`
公開: `dist/` を静的ホスティング(GitHub Pages等・非公式URL)へ。

## 構成
Vite + TypeScript(静的・追加FWなし)。`src/ImagePlaceholder.ts`(画像枠)、`src/data/news.ts`(お知らせデータ)、`src/layout.ts`(ヘッダー/フッター)。
画像差し替え: `data-ph` の要素を `<img>` に置換。

- 改善点: 内容が2020年度で停止/お知らせが古い/料金・アクセス詳細・講師・実績数値が見当たらない/FAQが見出しのみで回答が別ページ

## 表示方法
`dist/index.html` はビルド時にヘッダー・フッター・画像枠・お知らせを静的に埋め込み済みで、JSなし・ダブルクリックでも表示できます(メニュー開閉のみ小さなインラインJS)。編集後は `npm run build` で `dist/` を再生成してください。

## デザイン構成(v2)
- トップ: Hero(大判画像枠+インセット)→特徴(誰が・何が違うか)→カリキュラム(週コマ数)→コース比較表→費用/実績(未確認のため「確認中」)→学習環境→お知らせ/FAQ→相談導線
- 画像枠: `src/ImagePlaceholder.ts`。比率はCSSクラス `r-4-5` 等(`src/style.css` に定義)。インラインスタイルは使用しない。
- 費用・実績は現行サイトに記載がないため数字を載せていない。電話番号・受付時間は現行サイト記載(2020年時点)で要確認。
